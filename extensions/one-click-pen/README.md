# Infinity Pen - One-Click Screen Inking Extension

A fast, lightweight, and pressure-sensitive screen annotation browser extension built for Chrome, Edge, Brave, and other Chromium browsers.

## Features
- **One-Click Activation:** Press `Alt + P` or click the extension icon to instantly turn any website into a drawing canvas.
- **Hardware Pen Tablet Pressure:** Full stylus pressure sensitivity for Wacom, Huion, Apple Pencil, XP-Pen, and Surface Pens. Press hard for bold strokes, press light for fine details.
- **Catmull-Rom Smoothing:** Zero jitter, Apple-grade $C^1$-continuous Bézier curve smoothing.
- **Tools:** Pen, Highlighter, Eraser, Shapes (Arrow, Rectangle, Circle, Line).
- **Snapshot & Export:** Export your annotated screen as a crisp PNG image with 1 click.
- **Draggable Floating Toolbar:** Reposition the Apple-style glassmorphism toolbar anywhere on screen.

## Installation Instructions (Takes 30 seconds)
1. Open your browser (Google Chrome, Microsoft Edge, Brave).
2. Navigate to `chrome://extensions` (or `edge://extensions` in Edge).
3. In the top right corner, toggle **Developer mode** to **ON**.
4. Click **Load unpacked** in the top left.
5. Select this folder:  
   `.../infinity-notebook/extensions/one-click-pen`
6. Done! Click the puzzle icon in Chrome to pin **Infinity Pen**.
7. Navigate to any website (e.g. YouTube, Wikipedia, Google Docs) and press **`Alt + P`** or click the extension to start drawing!
