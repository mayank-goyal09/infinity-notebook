Infinity Notebook: 1-Click & Embed Showcase

Demonstrating how to embed an interactive whiteboard on any website, or trigger a 1-click floating screen-inking pen anywhere.

Method 1: Embedded Notebook Canvas

Embed an interactive inking notebook right inside any webpage, blog post, or learning dashboard:

Embedding Code:

<div id="my-notebook" style="height: 500px;"></div> <script src="infinity-notebook-embed.js"></script> <script> const notebook = new InfinityNotebookEmbed({ container: '#my-notebook', theme: 'light', pressureSensitivity: true }); </script>

Method 2: One-Click Floating Screen Pen

Notice the floating blue pen button in the bottom-right corner of this page! Click it (or press Alt+P) to turn this entire website into an inking canvas.

<script src="infinity-notebook-embed.js"></script> <script> // Adds 1-click floating pen to your whole website: InfinityNotebookEmbed.initScreenWidget(); </script>
